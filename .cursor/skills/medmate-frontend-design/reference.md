# Visual checks

- Hierarchy: one obvious title, scannable sections, no competing CTAs.
- Color: text `#0F172A` equivalent or `--mm-color-text`; muted at least `--mm-color-muted`.
- Interaction: `cursor-pointer` on clickable controls, 150–300ms color transitions.
- Responsive: no horizontal scroll at 375px; touch targets ≥ 40px.
- States: hover, focus-visible, disabled, empty, error.
- Icons: SVG only, consistent 24 viewBox.
